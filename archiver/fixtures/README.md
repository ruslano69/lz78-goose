Its historical build commands and feature statements are not current instructions.
Repeat its bytes and truncate to 2100000 bytes, as `bench_bzip2_memory.py` does.

`45908ba961f69a2514f1c89ab6d99c8504d1f2a08fbd5fc9d4d77472f601cdd1`.
